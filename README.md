## 一份提案，回答三个问题

| 客户现在在哪里？ | 市场机会在哪里？ | 接下来怎么做？ |
| :--- | :--- | :--- |
| 核查品牌、店铺与内容渠道，梳理已有优势和布局空白 | 分析品类、达人生态与可比竞品，找出有证据的机会 | 将研究转化为 90 天行动安排与阶段目标 |

适合跨境 MCN、达人营销团队及品牌出海顾问，在客户沟通前完成尽调，并组织成可演示的合作方案。重点面向东南亚与泰国市场。

## 工作流程

| 阶段 | 研究重点 | 产出 |
| :--- | :--- | :--- |
| **01 · 客户尽调** | 品牌归属、主营业务、招聘动向、海外布局 | 客户画像与渠道盘点表 |
| **02 · 渠道分析** | 店铺状态、商品结构、价格带、内容与互动 | 当前经营与内容机会分析 |
| **03 · 市场对标** | 品类规模、可比竞品、达人生态、平台规则 | 市场图表与竞品对标 |
| **04 · 提案交付** | 合作主张、阶段目标、执行安排 | 单文件 HTML 演示提案 |

## 提案长什么样

模板采用 **Neon Noir 深色风格**，以午夜蓝紫为底色，搭配霓虹粉、青色与金色强调信息，包含滚动动效及四个 ECharts 图表位。

**封面 → 客户画像 → 市场大盘 → 达人生态 → 竞品拆解 → 合作方案**

- **渠道盘点表**：集中展示品牌在电商与社媒渠道的布局。
- **市场与竞品图表**：呈现品类结构、市场增长、达人分层及 GMV 对标。
- **90 天合作方案**：将阶段动作、目标区间与合作理由放在同一条叙事线上。
- **数据来源汇总**：为提案中的数字保留出处、时间与统计口径。

## 快速开始

### 1. 获取文件

```bash
git clone https://github.com/bianzigege/crossborder-mcn-proposal.git
```

也可以通过仓库页面的 **Code → Download ZIP** 下载。

### 2. 在 AI 助手中使用

将整个文件夹放入你的 AI 助手支持的技能目录，保留 `SKILL.md`、`assets/` 与 `references/` 的相对路径。具体安装位置与调用方式取决于宿主工具。

提供品牌名、品类、目标市场及已知链接，例如：

```text
请使用 crossborder-mcn-proposal，为以下客户准备跨境 MCN 合作提案：

品牌：[中文名 / 英文名]
品类：[如小家电、美妆、家居]
目标市场：泰国
已知店铺或账号：[链接，可选]

请先完成客户尽调、渠道盘点和竞品分析，再基于模板生成 HTML 提案。
为关键数据注明来源、时间和口径，无法确认的信息请明确标注。
```

### 3. 生成并检查交付

以 `assets/proposal-template.html` 为骨架，替换文案与图表数据，输出到 `output/index.html`。交付前检查占位内容、来源标注、图表显示与页面效果。

> **使用环境**：本仓库提供技能说明、研究手册和 HTML 模板。原工作流引用的 `web-search` 与 `html-report` 技能未包含在内，需由宿主环境提供，或使用等效的联网检索与 HTML 制作能力。页面引用的外部资源需联网加载。

## 数据使用说明

研究手册和模板中的市场数字、费率、政策及案例应在每次正式提案前重新核验，不能直接视为当前事实。未检索到账号不等于账号不存在；应区分已确认的信息与待核实的判断。目标区间用于讨论和规划，不构成效果承诺。
