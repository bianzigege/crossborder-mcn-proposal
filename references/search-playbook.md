# 搜索手册：查询模板与数据源

所有搜索用 web-search skill。原则：**一次一个话题、中英泰三语轮换、先宽后窄**。品牌名太短（如 KAWU）会撞大量无关词，必须靠组合词收窄。

## Step 1 客户核查查询模板

| 目的 | 查询模板 | 说明 |
|---|---|---|
| 品牌归属 | `<品牌名> 百科` / `<中文名> <英文名>` | 百度百科条目通常给母公司、成立时间、商标号 |
| 母公司画像 | `<母公司名> 招聘` | 智联/BOSS 公司页含员工数、SKU 数、品牌矩阵、贴牌客户——信息密度最高 |
| 电商布局 | `<品牌名> Shopee` / `<品牌名> Lazada` / `<品牌名> TikTok Shop <国家>` | 官方店存在与否；Lazada 店铺页可直接 webfetch 确认在营 |
| 社媒布局 | `<品牌名> <国家> Instagram Facebook` / `<品牌名> tiktok <当地语言词>` | 查不到官方号 = 核心发现 |
| 招聘动向 | `<品牌名或母公司> 招聘` / `<母公司> 招聘 <城市>` | 看岗位类型判断扩张方向；新设子公司是品类扩张信号 |
| 海外布局 | `<母公司名> 海外 / 分公司` | 校招/就业网公司介绍页常列全部海外分支（金矿） |

**技巧**：
- 品牌的当地语言核心词（如泰国锅=กระทะ、หม้อ）+ 品牌名组合搜索，能探到本地账号
- FastMoss/Kalodata 的商品详情页会被搜索引擎收录，搜 `fastmoss <品牌名>` 可能直接拿到该品牌 TikTok 商品 GMV 数据
- 搜 `<品牌名> 出海 / 跨境` 可找到媒体报道

## Step 3 大盘与竞品数据源

### 优先数据源（公开可搜）
- **FastMoss / Kalodata / EchoTik**：TikTok Shop 各国类目 GMV、达人榜、小店榜、视频带货榜。搜索 `<市场> TikTok Shop <品类> GMV` 常能命中它们的报告转载
- **TikTok Shop 卖家大学**（seller.tiktokglobalshop.com）：佣金费率、政策调整公告——搜 `【泰国】TikTok Shop 平台费用`
- **行业报告转载**：book118 等文档站有完整市场报告（搜 `TikTokShop <国家>市场发展趋势洞察报告`）
- **跨境电商媒体**：AMZ123、大数跨境（10100.com）、亿邦、DoNews、卖家之家——竞品案例拆解文章的主要来源，搜 `<品牌名> TikTok 东南亚`
- **物流商博客**（喜运达等）：东南亚各国大盘数据汇编
- **泰国本地**：THECA（电商协会）、Priceza 消费者报告、Kommune Agency 达人营销报告

### 泰国市场关键基准数据（2025-2026，可直接引用）
- 电商总规模：2025 约 1.07 万亿泰铢（~330 亿美金），2027E 492.8 亿美金
- TikTok Shop：2025 前三季度 GMV 近 70 亿美金；美妆个护占 29% 第一，居家日用第 6
- 消费者：92% 依赖达人推荐（东南亚第一）；88% 因内容种草下单；TikTok Shop 使用率 51%
- 达人互动率：纳米 8.5% / 腰部 6.2% / 头部 3.8% / 明星 1.9%
- 合规红线：2026.6.30 起家电等 ~150 类商品 TISI 强制认证；2026.1.1 起取消 1500 泰铢以下进口免税；非 Mall 佣金约 8% 含税

### 竞品寻找方法
搜 `TikTok <国家> <品类> GMV 万美金`、`<国家> TikTok 卖了 万美金 <品类>`，找 2-3 个与客户供应链画像相似的已跑通品牌。需要抓的字段：单月 GMV、累计 GMV、达人数量、直播/短视频占比、代表性爆款内容、本地化动作（泰语 listing、本地仓时效）。
